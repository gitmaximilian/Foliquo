# Foliquo Community v0.14.1

This version brings the existing learning, translation and review tools into a more compact workflow, improves difficult document layouts, and adds encrypted local content search. It remains a local Community application; professional review is required.

## Changes

- Review compact sample and rule summaries, with clear active states, localized effects, expandable evidence and separate rule approval/sample activation. Local before/after examples use the real layout export path.
- Keep Foli's composer available while reading the chat. Persisted proposal confirmations link to their current rule; stale replacements require a fresh decision.
- Work through critical details, questions, source completeness and final review together. Jump to documented original pages/areas and linked translation blocks. Decisions and the explanation of applied rules belong to the saved result version.
- Edit and export supported columns, long tables, repeated headers, continuing rows and separate stamp/signature blocks. Preserve content and the original annex. Uncertain handwriting remains a question for the reviewer; PDF font substitution is disclosed.
- Organize explicitly related documents in dossiers, with separate people and confirmed preferred facts. Existing unassigned facts remain readable; neither identity nor factual corrections are inferred automatically.
- Inspect scan warnings page by page before translation. Rotate, crop and reorder working copies with a reversible original comparison. Scan checks are local heuristics and do not call a model.
- Inspect conservative local batch-grouping suggestions, move pages and confirm each group's language/options before starting. Retries and interrupted starts retain the intended job identities.
- Search saved translation and recognized source text locally, with marked excerpts, document/version labels and documented original locations. Include earlier versions explicitly and read long saved versions without entering current review. Pause/resume/rebuild the encrypted derived index; incomplete source/index coverage remains visible.

## Data, downloads and updates

Rules, samples, Foli history, dossiers, review decisions, usage and budgets remain in the encrypted per-user workspace outside installation directories. Original files remain unchanged. The search index is encrypted and rebuildable; backups retain primary records rather than copying this derived index.

Desktop update packages use the existing updater signatures and public keys. Browser/CLI distributions and Homebrew remain available through their separate paths. WinGet submission, operating-system signing/notarization and Cloudflare deployment are excluded from this work. Existing first-install trust prompts may remain.

## Practical limits

These changes do not train model weights or certify linguistic accuracy. Model output, OCR, source inventories, scan hints and reconstructed layouts require review. Missing locations are not fabricated. Pixel-identical output across systems is not promised; Word requests Aptos 11 while the local PDF runtime may substitute a font.

Content search uses only already stored text. It does not reprocess old image archives. Its build/read/page/document limits and the measured fictional archive scenario are described in [the content-search guide](https://github.com/gitmaximilian/Foliquo/blob/v0.14.1/docs/CONTENT-SEARCH.md). Those measurements are technical evidence, not fixed speed or translation-quality promises. ChatGPT quota and API costs remain unknown unless actually available from the provider.
