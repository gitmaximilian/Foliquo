# Translator practice test

This checklist is for a qualified translator evaluating the draft workflow. It is not a translation-quality claim or an acceptance certificate.

For ten representative, consented documents, record the document type, language pair, time spent, missing fields, OCR errors, name-spelling questions, date and number accuracy, stamp handling, PDF layout corrections, and whether the final document was usable after human editing. Use redacted or fictional documents in shared reports.

Do not upload these records to GitHub. Keep a short private summary of recurring defects and turn only reusable, non-personal conventions into explicitly approved style samples.
