# Foliquo Community v0.16.1

This update makes the route from upload to export easier to follow.

- Upload keeps advanced job settings folded and shows PDF group assignment in batch mode. If AI setup is needed for the selected files, it is the next action.
- A finished translation opens in review. The current version has a single primary route to download the PDF and Word together, with individual formats and detailed checks available on demand.
- Clarifications keep the original beside the answer on desktop. On phones, the source controls take you to the original and return focus to your answer.
- A saved correction takes you directly back to review on the new version. The optional learning offer is available once the version has been reviewed.
- Work in progress, questions, a paused queue and a reviewed version ready to export have distinct states.

Human review is required before the first final download of a version. Original pages remain available in the PDF and the existing local workspace is retained.
