# TranslateOCR 0.9.2

This browser-only update simplifies setup, translation and editing.

- AI settings live in the header and work directly in the first-run tour.
- Scan preparation and clarification questions open in focused dialogs.
- Partial answers and additional source files are saved in the encrypted local workspace.
- Choosing a suggestion confirms that question immediately. Explicit unreadable answers are available for every field.
- A compact jobs sidebar shows readable status labels, estimated progress and an animated outline during processing.
- Editing, direct downloads, the Guide and English/German/Arabic controls have been reorganized.
- Review polling preserves available downloads and source highlights.

## Install or update

Download the source ZIP, extract it and open the Setup-TranslateOCR file for your computer. For an update, stop the local service before replacing program files and keep the hidden `.local` folder. See the README for full instructions.

No native app installers or installable PWA are included. Translation drafts still require professional review and certification where applicable.

## Validation

89 automated tests, nine acceptance tests, an offline benchmark and the three-language demo build passed locally. GitHub Actions verifies Windows, macOS and Linux before the release tag is published.
