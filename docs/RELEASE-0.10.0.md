# TranslateOCR 0.10.0

This browser-only release hardens everyday use and keeps the public demo aligned with the local workspace.

The current TranslateOCR Community source is offered under PolyForm Noncommercial 1.0.0. Earlier releases published under MIT remain available under the terms that accompanied those versions. TranslateOCR Pro is a planned separate B2B offering; commercial terms and availability have not been announced.

- Style samples are selected only when both document type and target language match; unmatched documents keep the default layout.
- Version reporting comes from the package metadata. Release publication requires validation on Windows, macOS and Linux.
- Localized dynamic states, clearer recovery actions, source-region correction and shared demo question controls improve the workflow.
- Export/visual regression checks and a private practice-test harness distinguish technical validation from professional translation quality.

Download and extract the source ZIP. Stop the local service before updating. Keep `.local` and a separate encrypted backup. Follow the browser setup guide. No native app package is included.

Technical tests and fixture benchmarks do not establish real-world translation accuracy. Professional field testing and first-use testing on physical devices remain separate validation steps.
