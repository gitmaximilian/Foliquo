# Security policy

TranslateOCR processes sensitive identity documents. Please do not report a security issue in a public GitHub issue.

Until a private reporting address is configured, do not upload real documents, credentials, tokens, backups, or workspace files to GitHub. Contact the project maintainer privately using a channel they have published and include only a minimal reproduction with fictional data. Do not attempt to access another person's installation or data.

The default application binds to `127.0.0.1`. Do not expose it to a network or reverse proxy. The current release is not designed for hosted or multi-user use. A public issue or source upload is not a safe way to share a reproduction.
