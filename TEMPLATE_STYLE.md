# Style samples

Foliquo's Learn Style area accepts completed Word or PDF translations and extracts reusable document layout, field ordering, and phrasing conventions. It does not train a foundation model. Samples are stored in the encrypted local workspace and remain user-controlled.

Personal identities, dates, numbers, and other case-specific facts from a sample must never be copied into a new document. The current source document and explicit user answers always take precedence. Remove a sample from the Learn Style tab when it is no longer needed.
