# foliquo — Community edition

The general rules are in the parent `README.md`.

- `svg/`: vector masters, the first choice for web and app use.
- `png/`: raster exports in several sizes.
- `favicons/`: browser, Android and Apple touch icons.
- `brand-tokens.json`: colours, type and the mark's geometry.

Mark: two overlapping pages with translucent glass gradients (blue behind, violet in front). Wordmark: `foliquo`, Manrope 700, tracking `-0.05em`.

All files here are generated by `node scripts/build-brand.mjs`; edit that script, not the files.
